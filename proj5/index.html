Forward Function Implementation

def forward(im, t): """ Args: im : torch tensor of size (1, 3, 64, 64) representing the clean image t : integer timestep Returns: im_noisy : torch tensor of size (1, 3, 64, 64) representing the noisy image at timestep t """ with torch.no_grad(): alpha_bar_t = alphas_cumprod[t].to(im.device) epsilon = torch.randn_like(im) im_noisy = torch.sqrt(alpha_bar_t) * im + torch.sqrt(1 - alpha_bar_t) * epsilon return im_noisy

1.4 Implementing Iterative Denoising

In part 1.3, you should see that the denoising UNet does a much better job of projecting the image onto the natural image manifold, but it does get worse as you add more noise. This makes sense, as the problem is much harder with more noise!

But diffusion models are designed to denoise iteratively. In this part we implement this iterative process. We skip steps to speed things up, using a stride of 30 timesteps (starting at 990 and ending at 0). This creates a strided_timesteps list.

The iterative denoising process applies a specific update formula to move from a noisy image at timestep t to a less noisy image at timestep t'. This involves estimating the clean image x0 and interpolating.

1.6 Classifier Free Guidance (CFG)

In order to improve the quality of generated images, we use Classifier-Free Guidance (CFG). This technique computes both a conditional noise estimate (based on a text prompt) and an unconditional noise estimate (based on an empty prompt). The final noise estimate is a linear combination of these two:

ε = εu + γ(εc - εu)

where γ controls the guidance strength. Setting γ > 1 pushes the generation towards the conditional prompt, resulting in higher quality images.

1.7 Image-to-image Translation

In this part, we apply the SDEdit algorithm. By taking an original image, adding varying levels of noise, and then denoising it using the diffusion model, we can generate variations of the original image. The more noise added (lower starting index i_start, higher timestep t), the more the model "hallucinates" and deviates from the original. As the noise level decreases, the result remains closer to the original.

1.7.2 Inpainting

Inpainting allows us to replace specific parts of an image with new content while preserving the rest. This is achieved by using a binary mask. During the diffusion denoising loop, we force the pixels outside the mask to match the original image (with appropriate noise added), while allowing the model to generate new content inside the mask.

Inpaint Function Implementation

def inpaint(original_image, mask, prompt_embeds, uncond_prompt_embeds, timesteps, scale=7): # Start with random noise image = torch.randn_like(original_image).to(device).half() with torch.no_grad(): for i in range(len(timesteps) - 1): t = timesteps[i] prev_t = timesteps[i + 1] alpha_t = alphas_cumprod[t] alpha_prev = alphas_cumprod[prev_t] alpha = alpha_t / alpha_prev beta = 1 - alpha # Prepare tensor for UNet (CUDA) t_tensor = torch.tensor(t, device="cuda") # Conditional Pass cond_out = stage_1.unet( image.half().cuda(), t_tensor, encoder_hidden_states=prompt_embeds.half().cuda(), return_dict=False )[0] # Unconditional Pass uncond_out = stage_1.unet( image.half().cuda(), t_tensor, encoder_hidden_states=uncond_prompt_embeds.half().cuda(), return_dict=False )[0] # CFG Calculation noise_cond, pred_var = torch.split(cond_out, image.shape[1], dim=1) noise_uncond, _ = torch.split(uncond_out, image.shape[1], dim=1) guided_noise = noise_uncond + scale * (noise_cond - noise_uncond) # Ensure scalars are on correct device alpha_t = alpha_t.to(image.device) alpha_prev = alpha_prev.to(image.device) alpha = alpha.to(image.device) beta = beta.to(image.device) # Estimate x0 and x_prev x0 = (image - torch.sqrt(1 - alpha_t) * guided_noise) / torch.sqrt(alpha_t) x_prev = ( torch.sqrt(alpha_prev) * beta / (1 - alpha_t) * x0 + torch.sqrt(alpha) * (1 - alpha_prev) / (1 - alpha_t) * image ) # Add variance using the helper (Pass 't' as int or CPU tensor to avoid scheduler crash) x_prev = add_variance(pred_var, t, x_prev) # INPAINTING STEP: Force original pixels # We enforce pixels at the current target noise level (prev_t) noisy_original = forward(original_image, prev_t).half().to(device) # Combine: Keep generated content in Mask, keep Original content outside Mask image = mask * x_prev + (1 - mask) * noisy_original return image.cpu().float().detach().numpy()

1.8 Visual Anagrams

Visual Anagrams allow us to create optical illusions using diffusion models. By averaging the noise estimates from two different prompts—one applied to the original image and one applied to a flipped version—we can generate an image that looks like one thing right-side up and something else when flipped upside down.

The algorithm proceeds as follows:

ε1 = CFG(UNet(xt, t, p1))

ε2 = flip(CFG(UNet(flip(xt), t, p2)))

ε = (ε1 + ε2) / 2

Visual Anagrams Function Implementation

def visual_anagrams(image, prompt_embeds_1, prompt_embeds_2, uncond_prompt_embeds, timesteps, scale=7): # Ensure image is on correct device initially image = image.to(device).half() with torch.no_grad(): for i in range(len(timesteps) - 1): t = timesteps[i] prev_t = timesteps[i + 1] # Calculate alphas/betas alpha_t = alphas_cumprod[t] alpha_prev = alphas_cumprod[prev_t] alpha = alpha_t / alpha_prev beta = 1 - alpha t_tensor = torch.tensor(t, device="cuda") # ------------------------------------ # View 1: Normal Orientation # ------------------------------------ cond1 = stage_1.unet( image.half().cuda(), t_tensor, encoder_hidden_states=prompt_embeds_1.half().cuda(), return_dict=False )[0] uncond1 = stage_1.unet( image.half().cuda(), t_tensor, encoder_hidden_states=uncond_prompt_embeds.half().cuda(), return_dict=False )[0] noise1, pred_var = torch.split(cond1, image.shape[1], dim=1) noise1_uncond, _ = torch.split(uncond1, image.shape[1], dim=1) # CFG for View 1 eps1 = noise1_uncond + scale * (noise1 - noise1_uncond) # ------------------------------------ # View 2: Flipped (Upside Down) # ------------------------------------ # Flip image vertically (dim 2) flipped_image = torch.flip(image, dims=[2]) cond2 = stage_1.unet( flipped_image.half().cuda(), t_tensor, encoder_hidden_states=prompt_embeds_2.half().cuda(), return_dict=False )[0] uncond2 = stage_1.unet( flipped_image.half().cuda(), t_tensor, encoder_hidden_states=uncond_prompt_embeds.half().cuda(), return_dict=False )[0] noise2, _ = torch.split(cond2, image.shape[1], dim=1) noise2_uncond, _ = torch.split(uncond2, image.shape[1], dim=1) # CFG for View 2 + Flip back immediately eps2 = torch.flip(noise2_uncond + scale * (noise2 - noise2_uncond), dims=[2]) # ------------------------------------ # Combine & Step # ------------------------------------ # Average the noise estimates eps = 0.5 * (eps1 + eps2) # Estimate x0 x0 = (image - torch.sqrt(1 - alpha_t) * eps) / torch.sqrt(alpha_t) image = add_variance( pred_var, torch.tensor(t, device='cpu'), torch.sqrt(alpha_prev) * beta / (1 - alpha_t) * x0 + torch.sqrt(alpha) * (1 - alpha_prev) / (1 - alpha_t) * image ) return image.cpu().float().detach().numpy()

1.9 Hybrid Images

In this final part, we implement Factorized Diffusion to create hybrid images. Similar to Visual Anagrams, we combine noise estimates from two different prompts. However, instead of spatial flipping, we combine the low frequencies of one noise estimate with the high frequencies of another. This creates an image that looks like one thing from afar (low frequency) and another when viewed up close (high frequency).

The algorithm is:

ε1 = CFG(UNet(xt, t, p1))

ε2 = CFG(UNet(xt, t, p2))

ε = flowpass(ε1) + fhighpass(ε2)

Hybrid Images Function Implementation

def make_hybrids(image, prompt_embeds_1, prompt_embeds_2, uncond_prompt_embeds, timesteps, scale=7): """ Generates a hybrid image by combining low frequencies of eps1 and high frequencies of eps2. prompt_embeds_1: Corresponds to the LOW frequency image (seen from afar/blurred). prompt_embeds_2: Corresponds to the HIGH frequency image (seen close up/sharp). """ # Ensure image is on correct device image = image.to(device).half() # Define Gaussian Blur parameters kernel_size = 33 sigma = 2 with torch.no_grad(): for i in range(len(timesteps) - 1): t = timesteps[i] prev_t = timesteps[i + 1] # Calculate alphas/betas alpha_t = alphas_cumprod[t] alpha_prev = alphas_cumprod[prev_t] alpha = alpha_t / alpha_prev beta = 1 - alpha t_tensor = torch.tensor(t, device="cuda") # ------------------------------------ # 1. Estimate Noise for Prompt 1 (Low Freq Goal) # ------------------------------------ cond1 = stage_1.unet( image.half().cuda(), t_tensor, encoder_hidden_states=prompt_embeds_1.half().cuda(), return_dict=False )[0] uncond = stage_1.unet( image.half().cuda(), t_tensor, encoder_hidden_states=uncond_prompt_embeds.half().cuda(), return_dict=False )[0] noise1, pred_var = torch.split(cond1, image.shape[1], dim=1) noise_uncond, _ = torch.split(uncond, image.shape[1], dim=1) # CFG for Prompt 1 eps1 = noise_uncond + scale * (noise1 - noise_uncond) # ------------------------------------ # 2. Estimate Noise for Prompt 2 (High Freq Goal) # ------------------------------------ cond2 = stage_1.unet( image.half().cuda(), t_tensor, encoder_hidden_states=prompt_embeds_2.half().cuda(), return_dict=False )[0] # Note: We can reuse noise_uncond calculated above since t and image are the same noise2, _ = torch.split(cond2, image.shape[1], dim=1) # CFG for Prompt 2 eps2 = noise_uncond + scale * (noise2 - noise_uncond) # ------------------------------------ # 3. Frequency Combination # ------------------------------------ # Lowpass function f_lowpass_eps1 = TF.gaussian_blur(eps1, kernel_size=kernel_size, sigma=sigma) # Highpass function (Original - Lowpass) f_lowpass_eps2 = TF.gaussian_blur(eps2, kernel_size=kernel_size, sigma=sigma) f_highpass_eps2 = eps2 - f_lowpass_eps2 # Combine: Low Freq of Prompt 1 + High Freq of Prompt 2 eps = f_lowpass_eps1 + f_highpass_eps2 # ------------------------------------ # 4. Standard Step Update # ------------------------------------ # Estimate x0 x0 = (image - torch.sqrt(1 - alpha_t) * eps) / torch.sqrt(alpha_t) # Update image using your provided add_variance logic image = add_variance( pred_var, torch.tensor(t, device='cpu'), torch.sqrt(alpha_prev) * beta / (1 - alpha_t) * x0 + torch.sqrt(alpha) * (1 - alpha_prev) / (1 - alpha_t) * image ) return image.cpu().float().detach().numpy()

Conclusion

In this project, we explored the capabilities of diffusion models, starting from basic denoising loops to advanced techniques like Classifier-Free Guidance (CFG), SDEdit for image-to-image translation, and inpainting. We demonstrated how diffusion models can be controlled to generate high-quality images from text prompts, how they can "hallucinate" details to project sketches onto the natural image manifold, and how they can be manipulated to create optical illusions like visual anagrams and hybrid images. These experiments highlight the flexibility and power of diffusion models not just for generation, but for creative image editing and manipulation tasks.
