Part 1.1: Convolutions from Scratch

In this project, we explore 2D convolutions and filtering by implementing convolution operations from scratch using only NumPy. We start with basic finite difference operators and progress to more complex filters like box filters.

The goal is to build intuitions about how convolutions work by implementing them with nested loops, comparing results with built-in functions, and applying various filters to images.

Implementation Approach

I implemented convolution in two ways:

  • Four nested loops: Direct implementation iterating over output pixels and kernel elements
  • Two nested loops: Optimized version using vectorized operations for inner dimensions
  • Zero padding: Added proper boundary handling to maintain output size

Results were validated against scipy.signal.convolve2d to ensure correctness.

Code Implementation

Here are the two convolution implementations:

Four Nested Loops Implementation

def convolve_4forloops(image, kernel):
    image = image.astype(np.float32)
    H, W = image.shape
    h, w = kernel.shape
    pd_h, pd_w = h // 2, w // 2
    k = np.flip(kernel, (0,1))  # flip for true convolution
    padded = np.pad(image, ((pd_h, pd_h), (pd_w, pd_w)),
                    mode='constant', constant_values=0)
    out = np.empty((H, W), dtype=np.float32)
    for x in range(H):
        for y in range(W):
            s = 0.0
            for a in range(h):
                for b in range(w):
                    s += padded[x + a, y + b] * k[a, b]
            out[x, y] = s
    return out

Two Nested Loops Implementation

def convolve_2forloops(image, kernel):
    image = image.astype(np.float32)
    H, W = image.shape
    h, w = kernel.shape
    pd_h, pd_w = h // 2, w // 2
    k = np.flip(kernel, (0,1))
    padded = np.pad(image, ((pd_h, pd_h), (pd_w, pd_w)),
                    mode='constant', constant_values=0)
    out = np.empty((H, W), dtype=np.float32)
    for x in range(H):
        for y in range(W):
            patch = padded[x:x+h, y:y+w]
            out[x, y] = np.sum(patch * k)
    return out

Part 1.3: Derivative of Gaussian (DoG) Filter

The finite difference approach produces noisy results. By first smoothing with a Gaussian filter, we can significantly improve edge detection quality. Even better, we can combine both operations into a single Derivative of Gaussian (DoG) filter.

DoG Filter Visualization

Created DoG filters by convolving a 2D Gaussian with finite difference operators. These filters combine smoothing and differentiation in a single operation, making edge detection both cleaner and more efficient.

Key Insights

The DoG filter experiments reveal several important principles:

  • Noise suppression: Gaussian smoothing dramatically reduces noise in edge detection
  • Mathematical equivalence: DoG filters produce identical results to sequential blur-then-differentiate operations
  • Computational efficiency: Single DoG convolution is faster than two separate operations
  • Scale-space analysis: DoG filters form the foundation for multi-scale edge detection algorithms

This approach bridges basic convolution concepts with advanced computer vision techniques, demonstrating how mathematical theory translates into practical image processing solutions.

Part 2.1: Image Sharpening

The unsharp masking technique enhances image sharpness by amplifying high-frequency details. The process works by subtracting a blurred (low-pass filtered) version from the original image to isolate high frequencies, then adding these enhanced details back to the original.

The mathematical formulation is: Sharpened = Original + α × (Original - Blurred), where α controls the sharpening strength.

To evaluate the technique, I took a sharp image, artificially blurred it, then attempted to recover sharpness. This demonstrates both the capabilities and limitations of unsharp masking.

Observations: While unsharp masking can enhance perceived sharpness, it cannot fully recover details lost through blurring. The technique works best for enhancing existing details rather than recreating lost information.

Part 2.3: Gaussian and Laplacian Stacks

Gaussian and Laplacian stacks form the foundation for multiresolution image processing. Unlike pyramids, stacks maintain constant image dimensions across all levels, enabling frequency-selective operations without resolution loss.

Implementation Approach

The Gaussian stack applies progressive blurring without downsampling. The Laplacian stack captures frequency bands by computing differences between consecutive Gaussian levels, plus the final residual.

  • Gaussian Stack: G₀, G₁, G₂, ..., Gₙ (progressively blurred)
  • Laplacian Stack: L₀=G₀-G₁, L₁=G₁-G₂, ..., Lₙ=Gₙ (frequency bands + residual)
  • Reconstruction: Original = L₀ + L₁ + ... + Lₙ

Part 2.4: Multiresolution Blending (The Oraple!)

Multiresolution blending creates seamless image composites by blending images separately at each frequency band. This approach, pioneered by Burt and Adelson (1983), eliminates visible seams that plague simple alpha blending.

Algorithm Insights

The multiresolution blending process reveals several key insights:

  • Frequency-selective blending: Different frequency bands can have different blend ratios
  • Mask smoothing: Gaussian blurring of the mask creates natural transitions
  • Edge preservation: High frequencies maintain sharp details while low frequencies handle smooth regions
  • Perceptual quality: Results appear more natural than simple alpha blending

This technique forms the foundation for modern image compositing, panorama stitching, and computational photography applications.

Key Learnings & Conclusions

This project provided deep insights into the frequency domain nature of images and human visual perception:

  • Frequency decomposition is fundamental: Understanding images as combinations of different frequency components enables powerful processing techniques
  • Human perception is frequency-dependent: Distance affects which frequencies dominate our visual interpretation
  • Multiresolution processing is superior: Operating at multiple scales simultaneously produces more natural results than single-scale approaches
  • Implementation matters: Careful attention to boundary conditions, data types, and numerical precision is crucial for quality results

Most Important Learning: The realization that effective image processing requires understanding both the mathematical foundations (convolution, frequency domain) and the perceptual aspects (how humans see and interpret images). The combination of rigorous implementation with perceptual insights leads to techniques that are both theoretically sound and practically effective.
